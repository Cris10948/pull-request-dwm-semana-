# pull-request-dwm-semana-
# Mariscos "Mar Azul"

Maqueta frontend para el restaurante de pescados y mariscos **"Mar Azul"**. La página está armada en un solo archivo `index.html` siguiendo la estructura, secciones y colores del boceto a mano.

---

## 1. Colores usados (los del boceto)

- **Navbar y botones principales:** `#2362A1`
- **Fondo de la página:** `#121212`
- **Letras:** `#FFFFFF`
- **Tarjetas / bloques:** `#1B1B1B`

---

## 2. Estructura de la carpeta

Para que el diseño cargue las librerías locales y las fotos sin problemas, los archivos deben estar ordenados así:

```text
/carpeta-del-proyecto
  │
  ├── index.html
  ├── README.md
  ├── image_2b6f82.jpg      (Machas a la parmesana)
  ├── images.jpg            (Paila marina)
  ├── images (1).jpg        (Ceviche)
  ├── images (3).jpg        (Mariscal)
  │
  ├── css/
  │    └── bootstrap.min.css
  └── js/
       └── bootstrap.bundle.min.js
